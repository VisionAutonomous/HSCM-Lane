# Code availability

This repository provides the author-generated source code required to inspect, train, evaluate, and run inference with HSCM-Lane.

The repository does not redistribute BDD100K, TuSimple, pretrained backbone weights, generated figures, or trained checkpoints. Users should obtain datasets from their original providers and place them according to the README. Trained checkpoints, if released separately, should be linked through a stable archive such as GitHub Releases, Zenodo, or OSF.
